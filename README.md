# 🎮 BUGALHOS – TRÊS COVINHAS

Um jogo tradicional português de berlindes, recriado em 3D.

## Objetivo
Acertar nas três covinhas e conquistar os berlindes dos adversários.

## Regras
- Jogo num pátio de escola com chão de terra.
- Até 4 jogadores.
- Quem elimina um berlinde adversário fica com ele.
- Quem falha passa a vez.

## Modos de jogo
- Jogador contra computador.
- Multijogador local.
- Multijogador online (futuro).

## Plataformas
- Android
- iOS
- Windows
- Tablets
